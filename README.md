# 源声视界投影计算器

当前发布版本：v1.6.1。

**在线使用：[打开投影计算器](https://ssharpshoot.github.io/ysv-projection-calculator/)**

根据房间、幕布、座位与投影机参数，进行投距、规划亮度和观看几何的初步计算，提供交互式三维示意及PDF报告。

## 使用

- 打开页面先进入向导：场景与房间 → 幕布与位置 → 投影与安装 → 检查并生成；也可继续本机草稿或导入JSON。
- 已定幕布或已有投影机：使用相应入口，并按需锁定幕布、机型、吊点或座位。
- 手机底部切换参数、3D场景和计算结果。已有结果精简、收起与恢复功能保留。
- 在方案管理中填写名称、撤销/重做、恢复本机草稿、记录两份方案对比。
- 保存JSON配置可跨浏览器携带；PDF报告包含中文文本、输入条件、来源、待核验项与尺寸示意。

## v1.6.1 修复

安装检查模式直接显示定位尺寸、接线可用/所需空间及不足差额，列出待补参数，支持收展与填写跳转。手机顶部显示关键冲突。

## v1.6.0 新增

- 客厅电动幕及幕盒、出布口、黑边与下杆输入；三维收起/展开/安装检查。
- 幕面左右与前后定位、镜头/机身坐标、接线转弯/散热/维护净空；缺数据标待核。
- 电视、柜体、窗帘/轨道、梁等矩形障碍物与下降路径检查。
- PDF三维俯视/侧视、毫米定位表、末页等比微信二维码和明确咨询说明。
- 移动幕面时保持锁定镜头及座位的实际坐标；17项计算与流程回归测试、三视口与三类报告验证。

真实手机扫码与现场安装仍须核对，示意不是施工孔位图。

## 计算边界

亮度是厂商标称输入、当前损耗和幕布增益下的规划估算；ANSI/ISO/CVIA/lm分别保留，不做等价换算。宽银幕区分黑边、变焦填宽和变形镜头；附件适配与透过损耗须另核。

机型库含120款正式记录和1条自定义。90条允许参与投距初筛、30条待核；进入候选不代表实机光学安装已验证。缺少可靠官方来源身份的历史条目不参与自动推荐。固定吊点、移轴联动、机身及接线散热空间、座椅后仰与实际亮度仍需现场复核。三维及尺寸示意不作为施工放样图。

## 数据与运行

本工具没有账户或服务器保存方案功能。草稿和界面偏好使用浏览器localStorage，JSON与PDF由浏览器本地生成。打开机型来源链接会访问对应厂商网站。

本仓库为发布产物，index.html已内嵌运行库、样式、品牌素材和报告字体。当前验收覆盖Chromium内核的桌面/平板/手机尺寸、本地配置往返与实际PDF导出；直接双击、系统断网冷启动、其他浏览器及现场设备验收未完成。

GitHub Pages从main根目录发布。更新时同步替换已验证的index.html与publication-manifest.json，保留第三方许可。
